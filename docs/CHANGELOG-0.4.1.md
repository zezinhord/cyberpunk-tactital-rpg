# Cyberpunk Tactical RPG — versão 0.4.1

## Base
Consolidada sobre a versão 0.4.

## Alterações
- Identidade visual tropical cyberpunk aplicada à interface.
- Tokens de cores, paletas por distrito e medidas de toque adicionados em `src/theme/tokens.ts`.
- Emblemas SVG próprios para as seis origens e glifos de função adicionados em `src/ui/icons.tsx`.
- IBM Plex Mono incluída localmente para registros do Éden. Chakra Petch e Barlow Semi Condensed permanecem pendentes, com alternativas de sistema.
- Metadados e título atualizados para 0.4.1.
- Documentação corrigida: somente a Fase 1 foi integrada; a Fase 2 não está autorizada.

## Preservação
Esta integração não altera intencionalmente as mecânicas, regras, origens, salvamento, combate, mapa, nem o workflow Android da versão 0.4.

## Verificação
Integração de arquivos e revisão estática realizadas. Build completo e geração de APK ainda precisam ser executados no GitHub Actions.
